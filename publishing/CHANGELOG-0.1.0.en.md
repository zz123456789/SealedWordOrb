# 0.1.0 — Historical release

- Add the Sealed Word Orb creative item and the command editor.
- Store a command, permission level, optional description and Modified marker in item NBT.
- Require creative mode and operator permission to configure blank orbs.
- Prevent further editing after an orb is sealed.
- Allow holders to execute sealed commands using the saved permission level.
- Support both hands, block/entity interactions, English and Simplified Chinese.

**This historical version has reusable sealed orbs. Use 1.0.0 for single-use rewards.**

This is the original development build, formerly labelled 1.0.0, with its package version corrected to 0.1.0. Its implementation is unchanged.
